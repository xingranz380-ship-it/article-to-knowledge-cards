# make-knowledge-cards

将文章、笔记或本地 Markdown/TXT 文件转换为 5~8 张结构化知识卡片的 AI Agent Skill。

## 1. 项目解决什么问题

阅读长文后，核心知识点往往散落在各个段落中，复习时需要重新通读全文，效率低下。手动整理重点又耗时费力，还容易遗漏关键内容或混入个人臆测。

`make-knowledge-cards` 解决的问题是：**自动从文章中提炼真正重要的知识点，生成结构化、可复习的知识卡片**，让你在几分钟内掌握一篇长文的核心内容，而无需手动摘录。

它严格遵守"只提取原文有的信息"原则，不编造、不补充外部知识，确保卡片内容忠实于原文。

## 2. 主要功能

- **文章转卡片**：将粘贴的文章文本或本地 `.md`/`.txt` 文件转换为 5~8 张知识卡片
- **结构化卡片**：每张卡片包含标题、核心知识、简明解释、例子或自测问题四个字段
- **智能提取**：优先选择文章核心论点、反复强调的概念、支撑主旨的关键知识，而非均匀摘录每段第一句
- **自动去重**：同一概念在文中多次出现时，只生成一张卡片，整合各处的解释
- **一卡一点**：一张卡片只讲一个知识点，避免大杂烩（紧密相关的子概念可合理归组）
- **不强行凑数**：信息不足时宁可少做，纯叙事/抒情文章可生成 0 张并说明原因
- **语言一致**：输出语言与原文一致，不自动翻译

### 不支持的功能

- 网页抓取（不自动打开 URL 提取内容）
- PDF 文件解析
- 导出为 Anki 或其他闪卡格式
- 图形界面 / 交互式卡片展示

## 3. 安装方法

### 方式一：手动安装（推荐）

1. 克隆或下载本仓库到本地：

```bash
git clone <repository-url>
cd First_Skill
```

2. 将 Skill 目录复制到你的 AI Agent 的 skills 目录：

```bash
# 通用路径（以实际 Agent 配置为准）
cp -r skills/make-knowledge-cards ~/.agents/skills/
```

> 不同 Agent 平台的 skills 目录可能不同，请将 `make-knowledge-cards` 文件夹复制到你所使用 Agent 的技能加载目录中。

3. 重启 Agent 或刷新技能列表，确认 `make-knowledge-cards` 已被识别。

### 方式二：直接使用源码

本 Skill 是纯指令型（仅含 `SKILL.md` 和配置文件，无脚本依赖），你也可以直接读取 `skills/make-knowledge-cards/SKILL.md` 中的工作流指令，在任何支持自定义系统提示的 AI 对话中使用。

### 验证安装

使用官方验证脚本检查 Skill 结构是否合法：

```bash
# Windows (PowerShell)
$env:PYTHONUTF8=1
python path/to/quick_validate.py skills/make-knowledge-cards

# macOS / Linux
python path/to/quick_validate.py skills/make-knowledge-cards
```

预期输出：`Skill is valid!`

## 4. 使用方法

### 方式一：粘贴文章文本

直接在对话中粘贴文章内容，并发出指令：

> 把这篇文章转换成知识卡片

### 方式二：读取本地文件

提供本地 `.md` 或 `.txt` 文件的路径：

> 把 `notes/ai-intro.md` 转换成知识卡片

### 卡片结构

每张卡片包含以下四个字段：

| 字段 | 说明 |
|------|------|
| **标题** | 知识点的简短名称 |
| **核心知识** | 一句话定义或最关键的结论（不超过 2 行） |
| **简明解释** | 2~3 句话解释含义、原理或意义，用自己的话复述 |
| **例子 / 自测问题** | 原文中的具体实例/数据，或一道基于原文的简答题（二选一） |

**例子与自测问题的选择规则**：原文中有具体实例、数据、应用场景时优先使用例子；知识点是抽象概念、原理、方法且原文没有具体例子时使用自测问题。

### 输出格式

直接在对话中输出 Markdown 格式的卡片，每张卡片用 `## 卡片 N：标题` 分隔。不需要生成文件，除非用户明确要求保存为 `.md` 文件。

## 5. 输入输出示例

### 输入

以下是竺可桢《大自然的语言》的片段：

> 这些自然现象，我国古代劳动人民称它为物候。物候知识在我国起源很早。古代流传下来的许多农谚就包含了丰富的物候知识。到了近代，利用物候知识来研究农业生产，已经发展为一门科学，就是物候学。
>
> 物候观测使用的是"活的仪器"，是活生生的生物。它比气象仪器复杂得多，灵敏得多。物候观测的数据反映气温、湿度等气候条件的综合，也反映气候条件对于生物的影响。
>
> 首先是纬度。越往北，桃花开得越迟，候鸟也来得越晚。……经度的差异，是影响物候的第二个因素。凡是近海的地方，比同纬度的内陆，冬天温和，春天反而寒冷。

### 输出

```markdown
## 卡片 1：物候与物候学的定义

**核心知识**：物候指草木荣枯、候鸟去来等自然现象；物候学是利用物候知识研究农业生产的一门科学。

**简明解释**：这些自然现象我国古代劳动人民称为物候，古代流传下来的许多农谚就包含了丰富的物候知识。到了近代，利用物候知识研究农业生产发展为物候学，它记录植物的生长荣枯、动物的养育往来，从而了解气候变化及其对动植物的影响。

**例子**：桃花开、燕子来、布谷鸟叫，都是物候学记录的自然现象。

## 卡片 2：物候观测——"活的仪器"

**核心知识**：物候观测使用活生生的生物作为"活的仪器"，比气象仪器更复杂灵敏，能反映气候条件的综合及其对生物的影响。

**简明解释**：物候观测的数据反映气温、湿度等气候条件的综合，也反映气候条件对于生物的影响，应用在农事活动里比较简便、容易掌握。与传统气象仪器相比，生物本身就是最灵敏的气候感应器。

**自测问题**：为什么说物候观测使用的是"活的仪器"？它与普通气象仪器相比有什么优势？

## 卡片 3：纬度与经度差异对物候的影响

**核心知识**：纬度（越往北物候越迟）和经度（近海地区春天比内陆迟）是影响物候来临的两个主要地理因素。

**简明解释**：纬度方面，越往北桃花开得越迟、候鸟来得越晚，但南北差异日数因季节而异——冬季南北温度悬殊、夏季相差不大。经度方面，近海地方比同纬度内陆冬天温和、春天反而寒冷，所以沿海地区春天来临比内陆迟若干天。

**例子**：济南苹果开花在四月中或谷雨节，烟台要到立夏——两地纬度相差无几，但烟台靠海，春天便来得迟。
```
